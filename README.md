# AuctionPulse AI

**Know your max bid before you bid.** Paste a Copart / IAAI / Bid.cars listing link, VIN or listing text and get an investor report: verdict (GO / BE CAUTIOUS / WALK AWAY), maximum bid, itemized repair estimate, market value after repair, profit, ROI and risk flags.

> Status: **specification stage.** The app has not been built yet. Follow the build playbook to generate it with an AI coding tool.
